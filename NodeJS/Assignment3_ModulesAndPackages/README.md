# Assignment 03 – Modules & Packages

## Assignment Overview

This assignment focuses on understanding **Node.js modules, npm packages, and built-in modules**.

## Features

- Use the Lodash package for array operations.
- Remove duplicate values using `_.uniq()`.
- Find the maximum value using `_.max()`.
- Convert text into uppercase using `_.upperCase()`.
- Use the built-in `path` module.
- Extract file names using `path.basename()`.
- Get file extensions using `path.extname()`.

## Concepts Practiced

- Node.js modules
- npm and package installation
- Third-party packages
- Built-in modules
- `node_modules`
- Package management with npm
