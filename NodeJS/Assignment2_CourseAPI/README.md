# Assignment 02 – Course API

## Assignment Overview

This assignment focuses on building a basic **Course API server using Node.js built-in HTTP module**.

The API provides different endpoints to display course information, filter courses by level, generate greeting messages, and perform addition using query parameters.

## Features

- Display a homepage with available API endpoints.
- Show API information using a plain-text response.
- Retrieve all courses.
- Filter courses by level.
- Generate personalized greeting messages using query parameters.
- Add two numbers using query parameters.
- Handle invalid routes with a 404 JSON response.

## Concepts Practiced

- Node.js HTTP module
- Creating an HTTP server
- URL and query parameters
- JSON responses using `JSON.stringify()`
- HTTP status codes
- Content-Type headers
- Basic input validation
