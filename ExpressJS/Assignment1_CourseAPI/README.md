# Assignment 1 – Course API (Express)

## Assignment Overview

This assignment focuses on converting the previously created Node.js Course API into an **Express.js application**.

## Features

- Display a homepage with a Course API heading.
- Provide API information through a plain-text response.
- Retrieve all available courses.
- Filter courses by level using query parameters.
- Retrieve an individual course using its ID.
- Generate personalized greeting messages using route and query parameters.
- Add two numbers using route parameters.
- Handle invalid course IDs, invalid numbers, and undefined routes.

## Concepts Practiced

- Express.js framework
- Creating an Express server
- GET routes
- Route parameters (`req.params`)
- Query parameters (`req.query`)
- JSON and plain-text responses
- HTTP status codes
- Input validation
- 404 error handling
