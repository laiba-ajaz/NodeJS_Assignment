# Assignment – Bookstore API (Express.js)

## Assignment Overview

This assignment focuses on building a **Bookstore API using Express.js** to manage books, customers, and orders through different API endpoints.

## Features

- Display a bookstore homepage with a book search form.
- Check server health using a health endpoint.
- Retrieve all books and search books by name, author, or genre.
- Retrieve a specific book using its ID.
- Retrieve and filter customers by name or city.
- Retrieve and filter orders by status or order date.
- Retrieve a specific order using its ID.
- Generate receipt details for an order using its ID and email address.
- Log search filters and result counts using EventEmitter.
- Handle invalid requests and return appropriate 404 responses.

## Concepts Practiced

- Express.js and HTTP methods
- GET and POST routes
- Route parameters (`req.params`)
- Query parameters (`req.query`)
- Filtering arrays using `filter()` and `find()`
- Node.js EventEmitter
- Query String module
- JSON and plain-text responses
- HTTP status codes
- 404 error handling
